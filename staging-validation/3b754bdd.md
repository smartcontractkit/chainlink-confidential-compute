# Staging validation: ci/staging-validation-check

## Change

Adds the staging-validation PR check, its make targets, and the release-notes
generator. CI and tooling only; nothing deployed changes.

## Validation steps

None in staging. On this PR, confirm the `staging-validation` check passes with
this file present.

## Success criteria

The `staging-validation` check is green on this PR, and fails on a PR that adds
no `staging-validation/*.md` file or leaves a required section empty.

## Edge cases and risks

- Bot PRs (dependabump) and PRs labelled `no-staging-validation` skip the check.
- Adding or removing the label re-runs the check (`labeled`/`unlabeled` triggers).
