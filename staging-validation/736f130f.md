## Change

Confidential workflow events (capability started/finished, user logs) carry `shard_index` and `workflow_don_id` in CreInfo. Shipped by the capability plugin (framework); bumps chainlink-common.

## Validation steps

Run a confidential workflow on a sharded staging node and inspect the emitted `CapabilityExecutionStarted/Finished` and `WorkflowUserLog` events in Beholder.

## Success criteria

`CreInfo.ShardIndex` equals the node's configured shard and `WorkflowDonID` equals the consumer workflow DON; existing events keep flowing.

## Edge cases and risks

Nodes without the core change send shard 0. Additive proto fields only; roll back by reverting the plugin bump.
